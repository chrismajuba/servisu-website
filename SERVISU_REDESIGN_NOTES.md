# Servisu Website Redesign

This version keeps the original Servisu page structure and information, while upgrading the visual design with:

- modern responsive navigation
- clickable Servisu logo returning to the home page
- professional hero section with stock imagery
- animated cards and hover effects
- consistent legal/help/get-started page styling
- linked Google Play and App Store buttons
- refreshed footer with all original legal/support links

## Run locally

```bash
npm install
npm start
```

## Build

```bash
npm run build
```
